# 새뜸365 매니저

동네 약국 운영자 2명이 약국 PC의 웹브라우저에서 쓰는 **약국 운영 도우미 웹앱**입니다.
가격표 만들기, 매출 추이와 등락 원인 보기, 시즌 추천 상품과 포스터 만들기를 한곳에서 처리합니다.

> 바이브코딩 과정 실습 프로젝트입니다. 기획·계획·설계·점검 문서는 아래 "문서"를 보세요.

## 주요 기능 (1차)

### A. 가격표 만들기 (`/tags`)
- 약이름 · 가격 · 간단한 설명(40자 이내) **3칸만** 입력하는 고정 규격(가로 7cm × 세로 5cm)
- 가격을 바꿀 때 "변경 전 → 변경 후"를 확인받고, **±30% 이상** 바뀌면 오타 경고
- A4 한 장에 **10개**(2열 × 5행)씩 인쇄, "배율 100% · 머리글/바닥글 끄기" 안내
- 가격표 목록은 **이 컴퓨터의 브라우저에만** 저장 (서버에 올리지 않음)

### B. 매출 추이 · 등락 원인 (`/sales`)
- ERP에서 내려받은 매출 엑셀(.xlsx)·CSV를 **브라우저 안에서만** 읽음 (서버로 보내지 않음)
- 환자 이름·연락처 같은 **개인정보 열은 읽지 않고 버림**, 조제(처방) 매출은 계산에서 제외
- 주 · 월 · 분기 · 계절(일반 4계절 / 약국 시즌) **4단위** 합계와 추이 그래프
- 직전 기간 · 전년 같은 기간 대비 증감률 (휴무일을 뺀 영업일 일평균 기준)
- **±20% 이상** 변한 구간을 빨간 점으로 표시하고, 고르면 AI가 **"가능성"으로만** 원인 후보를 제시
  (근거 숫자는 앱이 계산하고, 근거가 없으면 "알 수 없음")

### C. 시즌 추천 상품 · 포스터 (`/season`)
- 다가오는 시즌을 고르면 **시즌 시작 2주 전**부터 "지금 준비할 때"로 안내
- 지난해 같은 시즌에 잘 팔린 **일반의약품 · 의약외품 5개**와 추천 근거 (전문의약품 제외, 자료 없으면 "추천 불가")
- A4 세로 1장 포스터 (제목 20자 이내): "완치 · 최고 · 100%" 같은 **단정·과장 표현을 자동 차단**하고,
  필수 안내 문구("복용 전 약사와 상담하세요.")를 넣으며, **약사가 문구를 확인해야 인쇄**

### 공통
- 공용 비밀번호 1개로 들어오는 화면 (`/login`), 개인 계정 없음
- AI(OpenAI)는 서버 쪽 코드에서만 부르며, **집계 숫자와 상품명만** 보냄 · 호출 횟수 제한과 월 사용 한도

## 기술 스택
- [Next.js](https://nextjs.org) 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- read-excel-file(엑셀 읽기) · papaparse(CSV 읽기) · recharts(그래프) · zod(입력 검사) · openai(AI 호출)
- 배포: Vercel

## 직접 실행해 보기

```bash
npm install
cp .env.example .env   # 값을 채워 넣기 (아래 표)
npm run dev            # http://localhost:3000
```

| 환경 변수 | 용도 |
|---|---|
| `APP_PASSWORD` | 공용 비밀번호 (12자 이상 권장) |
| `AUTH_SECRET` | 로그인 쿠키 서명 값 (16자 이상) |
| `OPENAI_API_KEY` | AI 호출 키 (서버에서만 읽음) |
| `OPENAI_MODEL` | 사용할 AI 모델 이름 |
| `AI_LIMIT_PER_MINUTE` · `AI_LIMIT_PER_DAY` · `AI_MONTHLY_TOKEN_LIMIT` | (선택) AI 사용 한도, 비우면 1분 5번 · 하루 50번 · 월 100만 토큰 |

비밀 값은 `.env`에만 두고 저장소에 올리지 않습니다(`.gitignore`). `npm run build`, `npm run lint`로 빌드와 코드 검사를 할 수 있습니다.

## 알아 둘 점
- 이 앱은 의학적 효능을 판단하거나 복약을 안내하지 않습니다. AI의 원인 후보와 추천 이유는 참고용 "가능성"입니다.
- 매출 자료는 서버에 저장하지 않습니다. 브라우저 탭을 닫으면 사라지므로 다시 올려야 합니다.
- 아직 보완 중인 항목은 [CHECK.md](CHECK.md)에 우선순위 순으로 정리돼 있습니다.
